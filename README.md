# Sachkunde-Training für Ismail

Lernseite für Sachkunde, Klasse 3, zum Thema **Ernährung**. Die Inhalte stammen von den Arbeitsblättern 1–11:

1. Ernährungskreis und Ernährungspyramide
2. Vom Tier oder von der Pflanze?
3. Gesundes und ungesundes Essen
4. Die Nährstoffe (Baustoffe, Brennstoffe, Reglerstoffe)
5. Der Weg der Nahrung
6. Fett und die Fettfleckprobe
7. Stärke und die Jodprobe

Zu jedem Thema gibt es eine kindgerechte Erklärung, Videos, Übungsspiele (u. a. eine virtuelle Fettfleckprobe und Jodprobe), Aufgaben wie auf den Arbeitsblättern mit Lösungen und ein Quiz mit Sternen. Dazu kommen ein Merkzettel und ein Probetest.

Reine HTML/CSS/JS-Seite ohne Build-Schritt: `index.html` im Browser öffnen oder über GitHub Pages veröffentlichen. Aufbau nach dem Vorbild von GK-lernen.
